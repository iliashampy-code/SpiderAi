# SpiderAI

Responsive Russian-language AI chat starter.

## Запуск
1. Установи Node.js 20+.
2. В папке проекта выполни `npm install`.
3. Скопируй `.env.example` в `.env`.
4. Заполни `AI_API_KEY`, `AI_BASE_URL` и `AI_MODEL` данными провайдера, поддерживающего совместимый с OpenAI Chat Completions API.
5. Запусти `npm start`, затем открой `http://localhost:3000`.

Не публикуй файл `.env` и не вставляй секретный ключ в клиентский JavaScript.

## Уже есть
- Адаптивный интерфейс
- Отправка сообщений и кнопки быстрых запросов
- История чатов в localStorage браузера
- Серверный endpoint для подключения совместимой языковой модели
- Понятный демо-ответ, если API пока не настроен

Перед публичным запуском добавь лимиты запросов, защиту от злоупотреблений, проверку входных данных и подходящую политику конфиденциальности.
